# ASTERIA — ほしのちいさな宿

旅人の小さなお願いをかなえて、5つの夜の思い出を集める、やさしい一画面ゲームです。

## 起動

Python 3 だけで動きます。

```sh
python3 serve.py
```

`http://localhost:4173` を開きます。別のポートなら `PORT=4174 python3 serve.py` のように指定できます。

## 遊び方

1. 旅人のお願いを読む。
2. 望遠鏡・星のお茶・花あかりからひとつ選ぶ。
3. 「これにする！」を押して、リアクションと星を受け取る。
4. 5人の旅人をもてなして、小さな星座を完成させる。

願いに合うおもてなしは星3つ。別の選択でも星1つと楽しい思い出が残ります。失敗やゲームオーバーはありません。

## 設計

複雑な経営要素を外し、短いコアループに絞って再設計しました。目的、ルール、選択、即時フィードバック、報酬、5夜の進行は [`GAME_DESIGN.md`](GAME_DESIGN.md) を参照してください。

- `index.html` — 一画面のゲームUI
- `style.css` — 絵本風のレスポンシブデザインとアニメーション
- `game.js` — 旅人、おもてなし、星の評価、思い出、セーブ
- `public/images/moonberry-camp.png` — ゲーム用に生成した星の小宿の背景イラスト

セーブデータはこのゲーム専用の `localStorage` キーに保存されます。以前のゲームのセーブとは共有しません。
