# ASTERIA — 小惑星リゾート

星々を旅する人たちのために、帰りたくなる宿を設計・運営する日本語の経営ゲームです。予約客の希望に合わせて客室を割り当て、施設を建てて隣接シナジーを生み、夜ごとの収支と評判を見ながらリゾートを育てましょう。

## 起動

Python 3 だけで動作します。依存パッケージのインストールは不要です。

```sh
python3 serve.py
```

`http://localhost:4173` を開いてプレイします。静的ファイルを配信できる任意のHTTPサーバーでも起動できます。

## 遊び方

1. **予約** — 旅人のプロフィール、希望、予算を確認し、今夜の客室を選びます。「おまかせ」で割り当てるか、客ごとに手動で選べます。
2. **島内図・建設** — 施設の設計図を選んで区画に建設します。施設は既存モジュールに隣接させて拡張。客室の近くに旅人の好みに合う設備を置くと、滞在の満足度が上がります。既存施設を選ぶと強化できます。
3. **夜をひらく** — 毎夜のイベント、部屋の適性、酸素・電力、施設維持費が満足度と収支に反映されます。結果から翌日の計画を立てましょう。
4. **思い出** — 満足した旅人から届いたポストカードを集めます。7夜ごとにシーズンレポートと準備金を受け取り、次のシーズンへ進みます。

ゲームの進行はこのブラウザーの `localStorage` に保存されます。ブラウザーのサイトデータを消去するとセーブも削除されます。

## プロジェクト構成

- `index.html` — ゲーム画面とアクセシブルな操作要素
- `style.css` — レスポンシブなリゾートUI
- `game.js` — 客、施設、満足度、収支、シーズン、セーブデータを扱うゲームロジック
- `public/images/asteria-resort.jpg` — リゾートのメインビジュアル
- `RESEARCH.md` — ゲームデザインと実装済みシステムの概要
- `media/demos/` — PRマージごとに記録する、SNS編集向けデモ動画アーカイブ

## 開発メモ: デモ動画のアーカイブ

PRをマージするたびに、そのマージ済みバージョンのデモ動画を撮影し、Gitで管理します。縦型9:16を基本に、横型16:9や正方形1:1など編集しやすい複数の画角を保存してください。PR番号とマージコミットでディレクトリを分け、撮影内容・解像度・尺・音声の有無を同梱のREADMEに記録します。詳しくは [`media/demos/README.md`](media/demos/README.md) を参照してください。
